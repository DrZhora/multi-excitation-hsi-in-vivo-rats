# ---------------------------------------------------------------------------
# BEFORE INSTALLING - two non-Python prerequisites
# ---------------------------------------------------------------------------
#
# 1. A full JDK is REQUIRED. Reading .im3 cubes goes through Bio-Formats,
#    which runs on a JVM via JPype. A JRE is not enough (the `jar` tool is
#    needed to resolve the Bio-Formats JARs).
#
#        brew install openjdk
#        export JAVA_HOME=/opt/homebrew/opt/openjdk
#
# 2. maven.scijava.org is unreachable on the lab network, so notebooks must
#    redirect scyjava to the OME Artifactory BEFORE the first bioio import
#    (once the JVM starts, the repository list is frozen until a kernel
#    restart):
#
#        import os
#        os.environ.setdefault('JAVA_HOME', '/opt/homebrew/opt/openjdk')
#        import scyjava.config as cfg
#        cfg._repositories.pop('scijava.public', None)
#        cfg.add_repositories(
#            {'ome': 'https://artifacts.openmicroscopy.org/artifactory/maven'})
#        # only now:
#        from bioio import BioImage
#        import bioio_bioformats
#
# After registering the venv as a Jupyter kernel, select it in the notebook:
#
#   python -m ipykernel install --user --name hsi-rats \
#       --display-name "Python (HSI rats)"
# =============================================================================
